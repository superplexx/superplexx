# Superplex

Superplex is a small group of 2 friends who create apps for their own enjoyment.

## Projects

- **[TricBar v2](https://github.com/superplexx/TricBar-v2)** — Customizes the Windows taskbar with Blur, Acrylic, and Liquid Glass effects. Lightweight and includes its own configuration tool.
- **[TricBar Linux v1](https://github.com/superplexx/TricBarLinux-v1)** — A port of TricBar for KDE Plasma 6; updates coming soon.
- [TricBar v1](https://github.com/superplexx/TricBar-v1) — An older version of TricBar-v2.
